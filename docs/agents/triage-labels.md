# Triage Labels

Optional settings for agent skills, such as [mattpocock/skills](https://github.com/mattpocock/skills), that read them. If you don't use such skills, ignore this file.

Maps generic triage roles to the label names used in this repo:

- **`needs-info`** → `incomplete`: waiting on the reporter for more information
- **`wontfix`** → `wontfix`: will not be actioned

The roles `needs-triage`, `ready-for-agent` (fully specified, ready for an AI coding agent) and `ready-for-human` have no label yet; a maintainer must create one before it can be applied. When a skill or tool refers to a role, apply the label shown.
